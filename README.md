## Pick a starting point

- **Building a prototype?** Explore BoltDIY and its local setup guide. It is a prototype workspace for technical users.
- **Working in an unfamiliar codebase?** Try Repository Context Engineer’s Python builders and agent instructions.
- **Using DeepSeek Harness?** Browse the plugins above. Each README covers installation, compatibility, behavior, and limitations.

## Feedback and contributions

Found a bug or a workflow worth improving? Open an issue in the relevant repository with your version, reproduction steps, and expected behavior. Keep credentials and private conversation data out of reports.

If a project is useful to you, a star is a welcome way to show support and bookmark it. Code contributions, clear bug reports, and practical feedback are welcome too.
